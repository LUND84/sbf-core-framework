# SBF Core Framework

一个从直播互动项目提取的 Node.js 技术分享快照：集中展示请求调度、访问控制、媒体片段验证、播放时钟、慢连接隔离，以及可选的付费互动状态模型。

这是框架源码与本地界面示例，不是当前生产部署副本。默认没有生成 worker、人物视频、直播流或支付配置，因此启动后 worker 离线、视频等待输入是预期状态；原因是本仓库只分享可阅读、可测试的公共框架，不携带私人基础设施或运行数据。

## 本地运行

使用 Node.js 22 或更新版本，并在仓库根目录执行以下命令；原因是源码使用原生 ES modules、Node 测试运行器与较新的 Node API。

```sh
npm install
npm run build
npm start
```

打开 <http://127.0.0.1:8080> 查看本地界面。`GET /healthz` 提供健康检查，`GET /api/status` 提供框架状态。构建步骤生成浏览器使用的依赖包；原因是前端源码中的包导入需要转换成可由静态服务加载的文件。

在另一个终端执行测试；原因是这些检查验证独立的调度、鉴权、媒体与状态合同，不需要连接私人服务器。

```sh
npm test
```

默认保留本机监听与关闭的外部能力；原因是无需配置任何私人账号，即可阅读界面、检查 HTTP 状态并运行测试。修改配置前可查看 `web/server/config.js` 和 `web/server/module-c/policies.js` 中的实际读取逻辑。

## 主要内容

| 部分 | 技术关注点 |
| --- | --- |
| HTTP / WebSocket 入口 | 分离观看会话、worker 身份与请求来源校验，限制输入和连接规模 |
| Broker 与互动队列 | 按互动类型调度，同优先级保持顺序，管理工作与播放生命周期 |
| 媒体验证与调度 | 验证片段格式、轨道及时间戳，将准备阶段与播放阶段分开 |
| 浏览器播放器 | 缓冲、播放时钟、可见性与重连状态协调 |
| 背压与诊断 | 隔离慢连接；以有限字段、容量和有效期收集播放报告 |
| Module C | 可选的订单、支付验证、持久化、权益与互动投递模型，默认关闭 |

模块关系、阅读入口和扩展接缝见 [架构说明](docs/architecture.md)。

## 分享边界

本快照排除了 GPU 生成实现与服务配置、实际 GPU API、SSH 连接与密钥、部署脚本与历史、生产环境变量、私人访问凭据、真实订单及日志、人物和背景媒体。原项目的完整工作目录与运行记录没有进入仓库。

`/ws/worker` 等入口仅保留通用协议合同；没有附带可连接的生成服务、私人地址或认证值。若实现自己的 worker，应从本仓库的消息处理与验证代码对齐协议；原因是入口存在本身不会生成内容，媒体数据还需符合实际验证合同。

Module C 保留公共链协议及公开网络常量，实际收款身份为空且功能默认关闭。请使用隔离测试数据研究扩展；原因是本地框架示例不需要真实付款，也不提供现成收款服务。
